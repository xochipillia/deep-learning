# Deep Learning Assignments

Sanitized implementations and experiments from a graduate Deep Learning
course.

## Assignments

- [ImageCLEF Visual MCQ test-time scaling](assignments/imageclef-test-time-scaling/README.md):
  controlled reproduction of zero-shot inference, self-consistency, increased
  decoding budgets, and guided answer repair with Qwen3.5-4B.

## Data Policy

Datasets, images, raw prompts, question identifiers, answer keys, model
weights, generated reasoning, and per-question predictions are not included.
The assignment downloads authorized resources into ignored local directories
when executed.

Only source code, configuration files, and aggregate metrics are prepared for
publication.

## Privacy

This publication copy excludes personal information, local filesystem paths,
credentials, cloud account identifiers, private academic records, team
communications, and instructor-provided files.
